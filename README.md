# dmelab

dmelab позволяет прочитать и записать прошивку BMW MS43 через FTDI K-line
кабель с компьютера Mac. Также можно читать и сбрасывать ошибки двигателя.

В репозитории находятся Rust-библиотека с CLI и [Android-приложение](apps/android/).
Ниже — инструкция для CLI, программы, которой управляют из терминала.

## Подойдёт ли для моего автомобиля?

Поддерживаемые ЭБУ:

- **Siemens MS43**, используемый с двигателями BMW M54.

Проверьте модель блока: одного совпадения модели автомобиля или двигателя
недостаточно. Для подключения нужен **FTDI K-line кабель**; инструкция
рассчитана на **macOS**.

Возможности:

- Сохранение полной прошивки и отдельных калибровок.
- Запись калибровок или программной части вместе с калибровками.
- Чтение и сброс ошибок.
- Просмотр параметров двигателя в реальном времени.
- Тесты DISA и вентилятора.

**Загрузчик (bootloader) при записи сохраняется.** Его перепрошивка
и восстановление не поддерживаются.

## Как прочитать и записать прошивку

### 1. Установите CLI

Выберите один из двух способов.

**Готовый бинарник из GitHub Releases.** Откройте раздел Releases этого
репозитория на GitHub и скачайте CLI для своего Mac. Распакуйте архив,
если сборка поставляется в архиве, и откройте папку с файлом `dmelab` в терминале:

```sh
chmod +x dmelab
./dmelab --help
```

Rust для этого способа не нужен. При запуске из этой папки в командах ниже
используйте `./dmelab` вместо `dmelab`.

**Из исходников через Cargo.** Потребуется Rust 1.95.0 с Cargo и rustup.
Скачайте репозиторий, откройте его папку в терминале и выполните:

```sh
cargo install --path crates/dmelab-cli --locked
```

После установки через Cargo команды доступны как `dmelab`. Если терминал не находит
команду, добавьте `~/.cargo/bin` в `PATH`.

### 2. Подключитесь к автомобилю

Подключите кабель к автомобилю и Mac. Включите зажигание, двигатель
оставьте заглушенным. Проверьте связь:

```sh
dmelab identify
```

Команда покажет идентификаторы ЭБУ и версию прошивки. Единственный
подключённый `usbserial`-адаптер выбирается автоматически.
Если порт не удалось выбрать, посмотрите список и укажите нужный:

```sh
dmelab ports
dmelab identify --port /dev/cu.usbserial-FT1234
```

Тот же `--port` можно добавить к любой команде ниже.

### 3. Сохраните исходную прошивку

```sh
dmelab read --mode full --output backup.bin
```

Будет создан полный образ размером **512 KiB**. Сохраните его перед внесением
изменений. Существующие файлы команда не перезаписывает.

Если нужны только калибровки — настройки двигателя:

```sh
dmelab read --mode partial --output calibration.bin
```

Размер файла калибровок — **64 KiB**.

### 4. Запишите подготовленный файл

Нужен совместимый с вашим ЭБУ и двигателем файл `.bin`.
Выберите режим по тому, что хотите изменить:

| Что записать | Режим | Подходящий файл |
| --- | --- | --- |
| Только настройки двигателя | `partial` | Калибровки 64 KiB или полный образ 512 KiB; версия прошивки должна совпадать с ЭБУ |
| Программную часть и настройки | `full` | Полный образ 512 KiB |

Запись только калибровок:

```sh
dmelab write --mode partial --input calibration.bin
```

Запись программной части и калибровок:

```sh
dmelab write --mode full --input firmware.bin
```

CLI проверяет файл и напряжение ЭБУ, исправляет контрольные суммы
автоматически и показывает прогресс. Исходный файл не изменяется.
В обоих режимах **bootloader не стирается и не записывается**.

После сообщения об успешной записи выключите зажигание, подождите
**10 секунд** и включите его снова.

[Подробнее о чтении и записи](docs/ms43-flash.md).
Справка по любой команде: например, `dmelab write --help`.

## Как прочитать и сбросить ошибки

```sh
dmelab dtc
dmelab clear-dtc
```

Первая команда читает ошибки, вторая очищает их. После сброса повторите
`dmelab dtc`, чтобы проверить результат. Ошибки пока выводятся кодами MS43
без текстовых описаний; неисправности, которые сохраняются, могут появиться снова.

## Параметры двигателя в реальном времени

```sh
dmelab live --watch
```

Показывает обороты, температуры, расход воздуха, коррекции, положения VANOS
и другие параметры. Остановка — **Ctrl+C**.
[Список параметров и выбор групп данных](docs/ms43-live-data.md).

## Исполнительные тесты

```sh
dmelab test-disa --state on
dmelab test-disa --state off
dmelab test-fan --duty-percent 50
dmelab diagnostic-end
```

Команды включают и выключают управление DISA или задают процент управления
вентилятором. После тестов выполните **`diagnostic-end`**, чтобы завершить
диагностическое управление: закрытие CLI не делает этого автоматически.
[Подробнее о тестах](docs/ms43-actuators.md).
