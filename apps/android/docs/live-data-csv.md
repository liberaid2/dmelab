# Логи Live Data в CSV

## Использование

На экране параметров включите «Записывать в CSV», затем запустите опрос.
Перед запуском выберите группы: параметры двигателя, VANOS, DISA. По умолчанию
выбраны все три; пустой набор не допускается. Выбор задаёт и опрос ЭБУ,
и столбцы CSV. Для изменения набора остановите опрос и создайте новую запись.
Разовое чтение не записывается. Карточка текущего файла показывает число
сохранённых наборов, время последнего набора от начала записи и размер в КиБ.
Уход с экрана не останавливает опрос или запись: ими владеет общий исполнитель
в foreground service. Переключатель нельзя изменить во время операции.

Во время непрерывного опроса удерживаем CPU через `PARTIAL_WAKE_LOCK`:
выключение экрана не отменяет обмен и запись. Lock освобождается после остановки
или ошибки, включая финализацию CSV; отмена сервиса также освобождает его
после завершения текущего native-вызова. Это не гарантия выживания процесса
или питания USB: особенности энергосбережения телефона проверяются отдельно.

После остановки доступны «Поделиться» через системное меню Android и
«Ещё → Сохранить как…» через системный выбор папки. Экспорт создаёт копию,
исходный CSV остаётся в приложении. «Ещё → Удалить» требует подтверждения.
«Ещё → Переименовать» меняет имя готового файла в приложении. Введите имя
без расширения: `.csv` и отметка `_partial` для частичного лога сохраняются.
Пробелы и кириллица разрешены; разделители пути, управляющие символы,
непереносимые символы имён файлов и точки по краям не допускаются. Основа имени
ограничена 200 байтами UTF-8, оставляя место для суффиксов. При совпадении
используется свободное имя с `-1`, `-2` и далее. Содержимое, время изменения
и порядок истории сохраняются. Активный или недоступный лог переименовать нельзя.
Для доступа без кабеля используйте «Логи» в верхней панели подключения:
откроется экран параметров с сохранёнными файлами; команды ЭБУ без подключения
недоступны. При ошибке чтения списка его можно загрузить повторно.

Чтобы отправить несколько CSV, удерживайте готовый лог или выберите
«Ещё → Выбрать». Список раскроется; нажимайте на карточки, чтобы добавить
или убрать файлы. Счётчик и «Поделиться» находятся в верхней панели.
Файлы передаются отдельными CSV через `ACTION_SEND_MULTIPLE` (один — через
`ACTION_SEND`), с MIME `text/csv`, FileProvider URI и временным read grant
для каждого вложения. Перед отправкой проверяется вся выборка; пропавший
файл вызывает ошибку, а не молчаливую отправку неполного списка.
Активная запись и недоступные файлы не выбираются. Back снимает выбор,
повторный Back закрывает экран. Выбор остаётся после меню отправки и поворота.

«Экспорт всех в ZIP» позволяет отправить архив через системное меню Android
или сохранить его через «Сохранить ZIP как…». В архив входят все готовые CSV
на момент подготовки, включая частичные и скрытые в свёрнутом списке.
Активная запись и недоступные файлы исключаются; чтобы добавить текущую запись,
сначала остановите опрос. Исходные CSV остаются в приложении. Если готовых файлов
нет или выполняется другая файловая операция, действие недоступно.

## Формат

UTF-8 без BOM, разделитель — запятая, строки — CRLF. Первая строка — заголовок.
Имена колонок постоянные, английские, snake_case; единицы указаны в имени.
Десятичный разделитель — точка независимо от языка телефона. Числа сохраняются
с точностью исходных значений UniFFI, без округления для UI. DISA — `true`/`false`.

Одна строка соответствует одному успешно прочитанному набору выбранных групп.
Не добавляем строки для ошибок и не дублируем старые значения.
`timestamp_utc` — ISO 8601 UTC в момент завершения чтения полного набора;
`elapsed_ms` — монотонное время от начала записи до его завершения.
Показания разных запросов Rust не являются атомарным одновременным измерением.
Частота записи соответствует фактической частоте полного опроса.
Непрерывный опрос использует `streamLiveDataSelected`: восстановительные ошибки пакетов
не завершают CSV и не создают строки. Следующий полный успешный набор продолжает
тот же файл; пропуск виден по временным меткам. Явная остановка завершает обычный
CSV, терминальная ошибка или отмена сервиса — частичный.

Первые две колонки всегда `timestamp_utc,elapsed_ms`. Затем идут только выбранные
группы в порядке: измерения → VANOS → DISA. Внутри файла схема не меняется.
При выборе всех групп — 35 величин и две временные колонки (37 столбцов).
Прежние файлы с 24 величинами остаются доступны без миграции; загрузка истории
опирается на первые две временные колонки, независимо от остальных полей.

Полный порядок колонок (невыбранная группа исключается целиком):

```text
timestamp_utc, elapsed_ms,
engine_speed_rpm, vehicle_speed_kmh,
accelerator_pedal_angle_deg, throttle_angle_deg, mass_airflow_kg_h,
intake_air_temperature_c, coolant_temperature_c, oil_temperature_c,
radiator_outlet_temperature_c, ignition_timing_cylinder_1_deg,
injection_time_bank_1_ms, idle_speed_integrator_pct, idle_air_control_duty_pct,
intake_camshaft_angle_deg, exhaust_camshaft_angle_deg, terminal_15_voltage_v,
lambda_integrator_bank_1, lambda_integrator_bank_2,
oxygen_sensor_heater_upstream_bank_1_duty_pct, oxygen_sensor_heater_upstream_bank_2_duty_pct,
oxygen_sensor_heater_downstream_bank_1_duty_pct, oxygen_sensor_heater_downstream_bank_2_duty_pct,
air_mass_per_stroke_mg, knock_signal_cylinder_2_v, knock_signal_cylinder_5_v,
cooling_fan_duty_pct, ambient_pressure_hpa, battery_voltage_v,
intake_vanos_actual_deg, intake_vanos_target_deg,
intake_vanos_reference_deg, exhaust_vanos_actual_deg, exhaust_vanos_target_deg,
exhaust_vanos_reference_deg, disa_command_active
```

В самом файле заголовок занимает одну строку без пробелов после запятых.
Сериализация определена в `common/session/data/LiveDataCsv.kt`.

## Хранение и сбои

Имя нового файла — `ms43_live_2026-11-03_16-45-00.csv`: дата и время
начала записи в часовом поясе устройства. При совпадении добавляем `-1`, `-2`
и далее перед расширением: `ms43_live_2026-11-03_16-45-00-1.csv`.
Учитываем готовые, активные `.csv.part` и частичные `_partial.csv`, в том числе
при переводе часов. Финализация и восстановление также сохраняют существующие
файлы, выбирая свободное имя; частичный суффикс остаётся после номера,
например `ms43_live_2026-11-03_16-45-00-1_partial.csv`.
Двоеточия заменены дефисами для совместимости
с файловыми системами. Внутри CSV `timestamp_utc` остаётся в UTC.
Старые файлы не переименовываются; после загрузки список сортируется по времени
изменения файла, независимо от формата имени и часового пояса.

Файлы находятся в приватном `files/live_data_logs/`, сохраняются между запусками
и исключены из Android backup/переноса. Удаление приложения удаляет их;
нужные файлы следует экспортировать. Автоматического удаления логов нет.

Запись потоковая на IO dispatcher, без накопления истории в памяти и очереди
запросов ЭБУ. Каждый полный набор сбрасывается из буфера. Экспорт старого файла
не удерживает блокировку писателя на время копирования.

Активный файл имеет суффикс `.csv.part` и недоступен для отправки. После
успешной остановки он становится `.csv`; после ошибки — `_partial.csv`.
Ошибка записи останавливает опрос с сообщением о доступе к файлу. Финализация
оставляет только подтверждённо сохранённый префикс; при наличии исходной ошибки
обмена ошибка финализации её не подменяет. Если финализация недоступна, карточка
предлагает обновить список и повторить восстановление.

После смерти процесса оставшийся `.part` восстанавливается как частичный CSV
при следующем открытии логов: незавершённая последняя строка отбрасывается.
Опрос автоматически не продолжается. Пустой файл без полного заголовка удаляется.
Сброс буфера защищает от потери истории при завершении процесса, но не является
гарантией сохранности при физическом сбое накопителя или отключении питания.

ZIP называется `ms43_logs_2026-11-03_16-45-00.zip`: время подготовки
в часовом поясе устройства. При совпадении с готовым или незавершённым архивом
добавляем `-1`, `-2` и далее перед `.zip`. CSV внутри сохраняют исходные имена и содержимое.
Архив создаётся потоково на IO dispatcher с отдельной блокировкой, без удержания
блокировки писателя Live Data и загрузки всех файлов в память. Ошибка чтения
любого исходного файла прерывает подготовку всего архива; неполный ZIP не выдаётся.

Временные архивы находятся в `cache/live_data_exports/`. При следующей подготовке
удаляются архивы и незавершённые ZIP старше 24 часов; Android может очистить кеш
раньше. Для длительного хранения используйте «Сохранить ZIP как…».

Для отправки используется FileProvider только для каталога логов и каталога
временных архивов, с временным разрешением чтения выбранного URI. Разрешение
на внешнее хранилище не требуется.
